# ニコニコ漫画 見開きビューア (Chrome拡張)

ニコニコ漫画 (`manga.nicovideo.jp`) の縦スクロール表示を、**見開き(2ページ)レイアウト**に変換して読みやすくする Chrome 拡張機能です。

## 仕組み

ニコニコ漫画の各ページは保護のため `<canvas>` 上に描画されています。この拡張は **サイト自身が描画した結果（canvas）をそのままスナップショットして再配置**するだけで、画像のダウンロードやコンテンツ保護の解除は行いません。あくまで自分が閲覧中のページを見やすく表示するためのものです。

1. 作品ページに「📖 見開き表示」ボタンを追加
2. クリックすると全ページを順にスクロールして描画させ、画像として取得
3. 取得後、フルスクリーンの見開きビューアで表示

## インストール（パッケージ化しない拡張機能の読み込み）

1. Chrome で `chrome://extensions` を開く
2. 右上の「**デベロッパーモード**」をオンにする
3. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
4. このフォルダ（`manifest.json` がある場所）を選択

## 使い方

1. ニコニコにログインし、漫画の作品ページ（例: `https://manga.nicovideo.jp/watch/xxxxxxx`）を開く
2. 右上の「📖 見開き表示」ボタンをクリック
3. 取得が終わると見開きビューアが開きます

### 操作

| 操作 | キー / クリック |
|---|---|
| ページ送り | `←` `→` / `Space` / 画面左右クリック |
| 先頭 / 末尾 | `Home` / `End` |
| 見開き ⇔ 単ページ | `S` ボタン |
| 右綴じ ⇔ 左綴じ | `R` ボタン |
| 見開きのズレを直す | `D` /「⇔ ずらす」ボタン |
| ずらしを全解除 | 「ずらし解除」ボタン |
| 閉じて通常ページに戻る | 右上「✕ 閉じる」 / 下バー「✕」 / `Esc` |

> 日本の漫画は通常 **右綴じ（右→左）** です。初期設定は右綴じ・表紙（1ページ目）単独表示にしています。

### 見開きのズレを直す（「⇔ ずらす」）

作品によっては、本来あるべき「表紙の次の白紙ページ」などが入っておらず、見開きの左右の組み合わせがズレることがあります。

**ズレている見開きを表示した状態で「⇔ ずらす」（または `D` キー）を押す**と、そのページ以降の組み合わせが1つぶんズレて直ります。もう一度押すと元に戻ります。途中から急にズレる作品では、ズレ始めたページで押せばそこから先だけを補正できます。すべて元に戻すには「ずらし解除」を押してください。

## 制限・注意

- `manga.nicovideo.jp/watch/*` でのみ動作します。
- ログイン状態で、自分が閲覧できる作品でのみ取得できます。
- **取得中はそのタブを前面（アクティブ）のままにしてください。** ニコニコ側はタブが非表示だとページ描画を止めるため、裏に回すと取得が止まります。取りこぼしがあった場合は自動でリトライし、それでも残ればダイアログで該当ページを通知します（タブを前面にして再実行すると取得できます）。
- ニコニコ側のページ構造（`#page_contents` / `.note` / `canvas`）が変わると動かなくなる可能性があります。その場合は更新が必要です。
- 取得は1チャプター単位です。チャプターを移動したら再度ボタンを押してください。

## ファイル構成

- `manifest.json` — 拡張機能の定義 (Manifest V3)
- `content.js` — ページ取得 & 見開きビューア本体
- `viewer.css` — ビューアのスタイル
